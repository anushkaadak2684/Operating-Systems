# Operating Systems

A collection of Operating Systems laboratory assignments implemented using **Shell Scripting (Bash)** and **C Programming**. This repository covers fundamental OS concepts such as process creation, IPC, signals, multithreading, synchronization, and classic operating system problems.

## 📚 Course Coverage

The repository contains practical implementations of:

- Linux Shell Scripting
- Process Creation and Management
- Zombie and Orphan Processes
- Inter-Process Communication (IPC)
- Signals and Process Control
- POSIX Threads (Pthreads)
- Producer-Consumer Problem
- Reader-Writer Problem
- Dining Philosophers Problem

## ⚙️ Compilation and Execution

### Shell Scripts

Grant execution permission:

```bash
chmod +x filename.sh
```

Run:

```bash
./filename.sh
```

### C Programs

Compile:

```bash
gcc filename.c -o output
```

Run:

```bash
./output
```

### Multithreaded Programs

Compile:

```bash
gcc filename.c -o output -pthread
```

Run:

```bash
./output
```
